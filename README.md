# 의료계 동향 대시보드

Gemini Spark가 수집·선별해 구글 시트에 쌓은 의료계 기사를 팀원이 함께 보는 페이지.

```
Gemini Spark ─→ 구글 시트 ─(GitHub Actions, 30분마다)→ data.json ─→ GitHub Pages ─→ 팀원 브라우저
```

- 팀원 브라우저는 GitHub Pages에만 접속하므로 구글이 막힌 망에서도 열람 가능
- '제외(중복)', '제외(불필요)' 기사는 공개하지 않음 (선별·검토필요만 표시)
- 시트 내용이 바뀐 경우에만 `data.json`이 커밋되어 날짜별 이력이 남음 (커밋 기록 = 동향 아카이브)

## 화면
| 탭 | 구성 |
|---|---|
| 오늘의 브리핑 | 가운데 핵심 키워드 클라우드 + 양옆 분류별 패널 (최신 3건) |
| 분류별 보기 | 분류별 열(건수·비중·기사 목록) + 키워드 TOP 10 · 일자별 기사 수 · 출처별 기사 수 |
| 전체 기사 | 뉴스형 목록 (대표 이미지 · 제목 · 요약 · 원문 보기) |

기간(오늘/7일/30일/전체)은 세 탭 공통. 주소 끝 `#brief`, `#cats`, `#list`로 특정 탭을 바로 열 수 있음.

## 파일
| 경로 | 역할 |
|---|---|
| `index.html` | 화면 (Pretendard Variable, shadcn/ui 스타일, Lucide 아이콘) |
| `assets/` | 폰트·아이콘 파일 (외부 CDN 차단 대비) |
| `data.json` | 시트에서 가져온 데이터 (자동 생성, 직접 수정하지 않음) |
| `thumbs.json` | 기사 원문 대표 이미지(og:image) 주소 캐시 (자동 생성) |
| `scripts/fetch-sheet.mjs` | 시트 CSV → `data.json` 변환, 제외 기사 숨김, 대표 이미지 수집 |
| `.github/workflows/update.yml` | 30분마다 동기화 + 배포 |

## 설정
- **Settings → Secrets and variables → Actions → Variables**
  - `SHEET_URL`: 구글 시트 주소 (공유는 "링크가 있는 모든 사용자 · 뷰어")
  - `SITE_TITLE`: 페이지 제목 (선택, 기본값 "의료계 동향")
- 즉시 갱신: **Actions → 시트 동기화 및 배포 → Run workflow**

## 시트 열 인식
1행은 머리글, 2행부터 데이터. 머리글 이름으로 열 역할을 자동 인식함 (`index.html`의 `RULES`).

| 역할 | 인식 기준 |
|---|---|
| 상태 | 값이 대부분 `선별…`/`검토…`/`제외…`인 열 (머리글 이름 무관) |
| 날짜 | 날짜, 일자, 게재일, 등록일, 수집일 |
| 제목 | 제목, 헤드라인, 기사명 |
| 분류 | 분류, 카테고리, 구분, 유형, 주제 (없으면 출처 기준으로 화면을 나눔) |
| 출처 | 출처, 언론사, 매체 |
| 링크 | 링크, URL, 주소, 원문 |
| 요약 | 요약, 내용, 본문 |
| 키워드 | 키워드, 태그 (없으면 제목에서 추출) |
| 이미지 | 이미지, 썸네일, 사진 (없으면 원문 대표 이미지 자동 수집) |
| 숨김 | 진행상황 (화면에 표시하지 않음) |
